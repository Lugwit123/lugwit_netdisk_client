# Lugwit 网盘客户端 · 使用说明

标题栏右上角 **❓** 随时打开这份文档。

## 这个东西是干什么的

跨地区传文件，公网带宽太贵。所以把百度网盘当中转：你上传一次，异地同事直接从网盘拉，
走网盘自己的 CDN，不吃自建带宽。

在这之上加了一层简化版 P4 版本管理：**改名、移动、回滚都不产生任何流量**。

|------|------|------|
| 左侧 | 🗂 版本库 / 📁 文件管理 / 🔀 传输列表 / ☁️ 网盘首页 | 四个页面切换，当前页高亮 |
| 右侧 | ◀ ▶ | 网页后退 / 前进 |

## 四个页面分别干嘛

### 🗂 版本库（主战场）

受版本管理的文件都在这。界面组件和 **Perforce P4V 一一对应**，只是配色改成了暗色：

| 区域 | P4V 对应 | 说明 |
|------|----------|------|
| 顶部文字菜单 | File/Edit/... | 文件·编辑·搜索·视图·操作·连接·工具·窗口·帮助 |
| 大图标工具栏 | P4V 工具栏 | 刷新·获取最新·提交 ∣ 签出·添加·删除·撤销 ∣ 差异·时间线·版本图 ∣ 移动·下载·锁定·解锁 |
| 路径栏 | depot 路径框 | 直接敲路径回车跳转，▾ 是最近去过的目录 |
| 左栏 | Depot / Workspace | depot 目录树，漏斗 ▼ 可按名字过滤 |
| 中栏 | Files / Pending | Files = 文件列表；Pending = 待提交变更列表 |
| 右栏 | 文件详情 | 选中文件的版本历史 |
| 底部 | Log | 每次操作的结果都往这里追加一行，出错也在这看 |
| 最底一行 | 状态栏 | 数据库状态·depot 根·待同步·最新提交·当前账号 |

灰掉的按钮（差异 / 时间线 / 版本图 / 取消 / Workspace / 书签）是后端还没有的功能，不是坏了。

**第一次用？让它带你走一遍**

版本库页面第一次打开会自动弹出新手教程，分两部分：

- **🎓 界面漫游** — 10 步，遮罩高亮每个区域并解释。`→` 下一步，`←` 上一步，`Esc` 退出
- **✅ 上手任务清单** — 右下角面板，7 个任务带你真跑一遍：
  浏览目录 → 添加文件 → 提交 → 签出 → 撤销 → 看历史 → 移动

任务**要真做完才打勾**，点一下不算。随时可以从 **帮助 → 新手教程** 重看，
**帮助 → 重置教程进度** 可以清零重来。

**两步工作流（和 P4 完全一样）**

改动**不会**立刻进版本库，要先进「待提交区」，再整批提交：

```
签出 / 添加 / 删除 / 移动  →  Pending 标签里堆着  →  点「提交」才真正产生版本
```

中途反悔点「撤销」，待提交区清掉、锁释放，**不会留下任何垃圾版本**。
这就是为什么文件名前会有角标：

| 角标 | 含义 |
|:---:|------|
| ✏ | 已签出，待编辑 |
| ➕ | 待新增 |
| 🗑 | 待删除 |
| ✂ | 待移动 |
| 🔒 | 被**别人**锁住，你提交会 409 |
| ⬇ | 你本地版本落后了 |

**提交文件**
1. 路径栏或左侧树进到目标目录
2. 工具栏「➕ 添加」，多选文件 → 条目进 Pending
3. 工具栏「📤 提交」，填说明 → 整批原子落库

相同内容的文件**不会重复上传**：
- `dedup` — 库里已有这个 blob，零网络
- `rapid` — 网盘秒传命中，零上行
- `uploaded` — 真传了

**看历史 / 回滚**

单击选中文件 → 右栏出现版本历史（也可以看底部「🕐 历史」标签）。
每版显示版本号、动作、提交人、大小、CL 号。

- 「⬇ 下载」取任意历史版本
- 「↩ 回滚」新建一版指向旧内容，**零流量**，历史不会被抹掉

**移动 / 重命名（零流量）**

- 选 **1 个**文件 → 工具栏「✂ 移动」→ 填完整新路径，改名和移动一步到位
- 选 **多个** → 填目标目录，各自保留原文件名
- 目录右键「移动目录」→ 整个目录搬走，所有文件收进同一个提交

网盘里的文件一个字节都不动，只改数据库记录。提交后源路径写一条 delete、目标写一条 move。

**签出（p4 edit）**

选中 → 工具栏「✏ 签出」。签出后别人无法提交这个路径，会收到 409。
适合 psd / max / ma 这类没法合并的二进制文件。提交完成后锁自动释放。

**右键菜单**

文件行右键：签出 / 添加到待提交 / 标记删除 / 移动·重命名 / 撤销 / 提交所在变更列表 /
获取最新 / 下载 / 查看历史 / 锁定 / 解锁。目录行和树节点也各有一套。

临时文件、参考图放这，不用占版本库。

### 🔀 传输列表

正在传的任务。

账号信息、容量。

## 状态栏那几个字段是什么意思

版本库页面最底下一行：

- **●** — 版本数据库连接状态。绿色 = 正常，红色 = 连不上
- **depot 根** — 网盘上存内容的位置，固定 `/apps/Lugwit/.depot`
- **待同步** — 你本地版本落后于最新版的文件数（相当于 `p4 sync -n`）
- **最新提交** — 最近一次 CL
- **👤** — 当前账号

## 网页在客户端里能直接用本地能力

客户端里的页面（QWebEngineView 承载的那套网页）会注入 `window.lugwitBridge`，
浏览器里没有这个对象。网页据此做特性检测，同一套页面浏览器/客户端两用。

除了选文件、算 md5（秒传）、列本地目录这些既有能力，桥还提供**版本库本地读取**：

| 槽 | 作用 |
|---|---|
| `depotBase()` | 当前 depot 服务基址 + 是否已拿到登录态 |
| `depotList(dir, ws)` | 列版本库目录（绝对逻辑路径，如 `/notes/rez_pkg`） |
| `depotDownload(path, rev)` | 取文件内容（文本回 `text`，二进制回 `base64`） |
| `depotVersions(path, ws)` | 文件版本历史 |

**登录态**：网页（网盘 UI）里登录后，`lugwit_token` cookie 存在持久化 profile 里；
桥通过 `cookieStore().cookieAdded` 抓到它，调用 depot 服务时带上
（`Cookie: lugwit_token=…`），因此**不必再绕托盘中转或 nginx `/baidu` 网关**。
cookie 还没抓到时可临时用环境变量 `LUGWIT_ACCESS_TOKEN` 兜底。

> 注意：版本库**列表**只查 Postgres，离线可用；**取内容**要经百度网盘
> （`pan.baidu.com`），机器连不上外网时会报 500。

## 出问题了

**操作没反应 / 不知道哪错了**
先看底部 **Log** 面板，每次操作成功失败都会记一行。

**页面空白，只有标题栏**
版本库里确实没文件。添加一个再提交就有了。

**红点 / 数据库显示"不可用"**
版本数据库连不上，找管理员。

**打不开服务**
标题写着"打不开服务"就是这个地址的 `/baidu/` 打不开（页面 404 或服务没起）。

默认走 nginx 统一入口：开发机 `http://127.0.0.1:8080`，部署机取域名。
别指到 `1027`——那是认证服务自己的端口，`/baidu/` 只有它进程内挂载了网盘子应用
才有，开发机默认没有，直连必然 404。

排查三步：

```bat
curl -o NUL -w "%%{http_code}\n" http://127.0.0.1:8080/baidu/    :: 期望 200
netstat -ano | findstr ":1028"                                   :: 网盘服务要 LISTENING
wuwor lugwit_baidu_netdisk -- netdisk_status                     :: 或在包环境里看状态
```

换地址用 `--url`：

```bat
wuwor lugwit_netdisk_client -- netdisk_client --url http://别的地址:8080
```

**提交时报 409**
文件被别人签出了，提示里有是谁。

**界面整个崩了**
标题栏 🔃 重启。白屏或弹「渲染进程退出」多半是 Qt/PySide6 环境没装好：

```bat
:: 启动输出里应有 "[netdisk_client] PySide6 合并完成: 硬链接 N / 复制 M -> ..."
:: 没有或 pyside6 版本换过 → 删掉合并缓存强制重做，再启动
rmdir /s /q D:\TD_Depot\Software\Lugwit_syncPlug\lugwit_insapp\trayapp\rez-package-3rd\.pyside6_merged
wuwor lugwit_netdisk_client -- netdisk_client
```
